# Statischer Erstentwurf (v1) – nur als Inhaltsquelle

Dieser Ordner enthält den statischen HTML-Entwurf der Homepage (Design-Studie
auf Basis des Bezirks Saar-Hochwald, mit echten, von dpsg-trier.de
übernommenen Inhalten). Er wird **nicht mehr deployt** – die Live-Version
dieses Entwurfs bleibt unverändert auf dem Branch
`claude/dpsg-trier-homepage-design-jwdgs4` bzw. `v1-erstentwurf` erhalten.

Der Ordner dient im Custom-CMS-Projekt (siehe `/docs/pflichtenheft.md`) als
**Inhaltsquelle**: Die hier bereits recherchierten und aufbereiteten Texte
(Chronik der Vorstände, Rechtsträgerstruktur, Stufen-Beschreibungen,
Diözesanverband, Aktuelles-Beiträge) sollen beim Aufbau der redaktionellen
Inhalte im neuen CMS (Phase 1a, siehe Pflichtenheft Abschnitt 12) übernommen
und nicht neu recherchiert werden.
